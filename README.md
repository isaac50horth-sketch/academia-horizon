# Académie Horizon

Site premium pour la vente de formations digitales et abonnement récurrent.

## Déploiement

1. Connectez ce repository à Netlify (app.netlify.com).
2. Déploiement automatique à chaque push.

## Paiements Stripe

Remplacez les placeholders `STRIPE_LINK_*` dans index.html par vos vrais Payment Links.

Produits recommandés :
- IA Maîtrise Totale : 97€ (one-time)
- Business Digital 6 Figures : 197€ (one-time)
- Club Horizon : 29€/mois (subscription)

## Contenu des formations

Programmes détaillés disponibles dans le dossier `formations/`.

## Prochaines étapes

- Créer les produits et Payment Links dans Stripe Dashboard ou via API.
- Ajouter une page de remerciement avec accès au contenu.
